# 模型

模型使用 `libriichi` 生成的 Mortal v4 公开观测，输入形状为 `1012 × 34`。

## 结构

| 部分 | 结构 | 参数量 |
| --- | --- | ---: |
| 共享编码器 | 256 通道、54 个预激活残差块、通道注意力、1024 维输出 | 23,663,488 |
| 状态预测 | 1024 维适配层 | 1,900,350 |
| 后续结果 | 768 维适配层 | 990,216 |
| 动作策略 | 46 个动作 | 47,150 |
| 合计 |  | 26,601,204 |

状态分支一次输出 830 个值，中间宽度为 1024；后续结果分支一次输出 264 个值，中间宽度为 768。两个适配层都没有形成低秩输出瓶颈。

状态预测包括对手向听、振听或无役、牌张放铳率、对手暗牌数量和牌山数量。后续结果包括对手宝牌与打点、小局结果、局收支、终局顺位和分数。动作策略学习牌谱中的实际选择。

## 标签

- 对手向听、振听或无役、牌张放铳率使用逐事件完整手牌状态计算。
- 对手暗牌和未公開牌山使用 `0..4` 分类标签；三种红五另使用 `0..1` 分类标签。
- 对手宝牌和打点只在该玩家最终和牌时计算损失，同时学习离散分布和独立标量。宝牌分为 `0..6` 和 `7+`；打点使用规则中实际存在的59个结算档位，包括子家四番30符荣和7700点、三倍满、双倍役满和叠加役满。
- 小局结果分别学习是否有人和牌，以及有人和牌时四家各自是否和牌。双响和三响可以有多名玩家同时成立。
- 终局顺位使用四家顺位的 24 种联合排列。
- 动作标签使用 Mortal v4 的 46 动作空间和合法动作掩码。

## 数据划分

训练集从 2025 年牌谱中按文件名哈希稳定选取 `1/20`，共 8,944 局。验证集使用 2026 年牌谱中与 Mortal 数据准备脚本相同的 MD5 分桶留出，共 246 局。

每个公开事件至少保留一个固定视角；存在可监督动作时，同时保留作出动作或明确放弃动作的视角。观测用双位图和稀疏 `float16` 数值压缩保存。宝牌标签会重复计算相同的宝牌指示牌；打点标签不包含本场和供托。

## 运行测试训练

建立 Python 3.11 训练环境后，运行 `scripts/run-training-test.ps1`。指定 2025 年牌谱目录、2026 年压缩包和 Mortal Python 模块目录后，脚本会生成清单、转换数据、训练一轮并导出推理权重。已经完成的单局分片会直接复用。
